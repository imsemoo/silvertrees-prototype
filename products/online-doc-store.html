about Online Doc Store

An innovative product from silvertrees web development, which makes sharing and storing documents a breeze.

With your online doc store account, you receive your very own website and sub-domain (for example: mysite.onlinedocstore.net). Your online doc store website comes fully equipped with an easy admin, which allows you to customize your page content, add and manage your clients (users) and upload unlimited file types. With online doc store's basic 2GB package; uploading, sharing and collating files and documents has never been easier. Flag documents and files with the option to automatically notify users of new files. Each client (user) you add, receives their own secure login, from where can upload files and view all documents you have made available to them.

what you get

  • Secure client access to document & files
  • Easy admin – add and notify clients in seconds
  • Unlimited file types / extensions
  • 2GB basic package
  • Manage maximum file size
  • Easy upgrade to larger storage
  • Daily Backup – Weekly backup – Monthly offsite backup
