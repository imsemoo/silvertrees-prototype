which file tool

filexchange or online doc store?

Same security, different size. FileXchange is the light-weight version of Online Doc Store.

FeatureFileXchangeOnline Doc Store
what it isThe light-weight versionThe full product, from a 2GB basic package
where it livesInside your existing website, or on its ownIts own website and sub-domain
client loginsYesYes, each client uploads and downloads
