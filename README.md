# Silvertrees prototype

Redesign prototype of the Silvertrees visual identity and website. The identity idea is "small beginnings": a disc, a seed, a moat, a notch, tracked lowercase, growth rings and hard-hat yellow.

**Live:** https://imsemoo.github.io/silvertrees-prototype/

Static HTML, CSS and JavaScript. Pages are generated with `tools/build.py`.

Built by [Islam Nasser](https://imsemoo.github.io/eslam-portfolio/).
